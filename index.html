Import Backlog Applications

Upload an Excel file to bulk-import already-issued ID applications. Records are created in Approved status.

Expected columns: full_name*, organization*, employee_number, gov_id_number, blood_type, mobile_number, whatsapp_number, email, date_joined, reports_to

Column headers are flexible — e.g. Full Name, Company, Phone all work.


Import Induction (Excel) — New Applications

Upload the client's Induction Form template. Each row creates a new Full-form application in Pending Security Clearance, tagged Excel Import — this is different from the Approved-status backlog import above.

Expected template: sheet induction form, columns No., PROJECT, Company Name / Employer, Full Name, Gender, Nationality, Date of Birth, ID Type, Iqama / Business Visa / National ID Number, Iqama / National ID Expiry Date, Date Joined, Mobile Number, Email, Blood Type, Sponsor Name, Insurance Expiry, Language, Subcontractor, 3rd-Party Sponsor, Legal Agreement copy, Legal Agreement Expiry, Job / Trade, Location, Safety Induction Date, Project ID, Re-New Project ID, DAMAGED, LOST, RETURN, INACTIVE / ACTIVE.
